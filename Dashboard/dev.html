          API contract used by this dashboard

Public
  POST  /api/auth/login
  POST  /api/incidents/report
  POST  /api/incidents/report-video   (multipart/form-data)
  POST  /api/devices/register
  POST  /api/devices/:deviceId/heartbeat

Protected (JWT)
  GET   /api/auth/me
  GET   /api/dashboard/stats
  GET   /api/incidents/
  PATCH /api/incidents/:id/verify
  PATCH /api/incidents/:id/reject
  POST  /api/incidents/:id/dispatch
  POST  /api/incidents/:id/respond
  POST  /api/incidents/:id/resolve
  GET   /api/cameras/        GET /api/cameras/:id
  GET   /api/devices/        GET /api/devices/:deviceId
  GET   /api/units/
  GET   /api/reports/

Admin only
  POST/PUT/DELETE  /api/cameras/(:id)
  POST/PUT/DELETE  /api/units/(:id)

Realtime (Socket.IO)
  incident:new · incident:update · incident:dispatched
  incident:responding · incident:resolved
  device:registered · device:online · device:offline · device:update
  dashboard:update
